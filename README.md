# Observability and Feature Flagging — Talk Repository

Working repository for the talk **"Observability and Feature Flagging — Why
observability companies invest in feature flagging, and how you can benefit."**

The talk explores the convergence of observability and feature flagging, the
acquisitions driving it (Dynatrace/DevCycle, Datadog/Eppo), and the role of the
open standards **OpenFeature** and **OpenTelemetry** — in particular the
OpenTelemetry feature-flag semantic conventions that OpenFeature contributed to.

## Contents

- [docs/talk-foundation.md](docs/talk-foundation.md) — abstract, agenda, the
  unique narrative hook of the talk.
- [docs/research-notes.md](docs/research-notes.md) — summarised research from
  Dynatrace, Datadog, Statsig and OpenFeature; the gap each acquisition leaves
  open that this talk fills.
- [docs/demo-spec.md](docs/demo-spec.md) — the three demo scenarios that will
  be implemented on top of the OpenTelemetry community demo, mapped to the
  talk's pillars.
